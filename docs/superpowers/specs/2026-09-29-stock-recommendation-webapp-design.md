# Stock Recommendation Web App — Design

## מטרה

אפליקציית web אישית (משתמש יחיד) שסורקת מניות מ-S&P500 + Nasdaq, ממליצה על
10-20 מניות לפי ניתוח טכני, ומאפשרת ניהול תיק השקעות וירטואלי (בלי חיבור
לברוקר אמיתי — כל "קנייה/מכירה" היא רק רשומה באפליקציה).

מבוסס על מסמך אפיון שהמשתמש הכין (`אפיון לאפליקציית מניות.docx`), עם
התאמות שהוסכמו בשיחת עיצוב:

- מחליף לגמרי רעיון קודם של שירות רקע + בוט טלגרם להתראות בזמן אמת.
- הפלטפורמה: Web app (responsive, ניתנת ל"הוספה למסך הבית" באייפון כ-PWA)
  כדי לעבוד גם במחשב וגם בטלפון מהיום הראשון, בלי לבחור סדר בנייה.
- קריטריוני ה"שיטה הטכנית" של המסמך המקורי אינם ידועים בפירוט, ולכן v1
  משתמש בסט כללי טכני גנרי וסטנדרטי (ר' "מנוע המלצות" למטה), הניתן
  להחלפה בעתיד כשיוגדרו הכללים המדויקים.

## ארכיטקטורה

```
┌─────────────────────────────────────────────┐
│  React SPA (Vite, PWA)                       │
│  4 מסכים: תיק │ המלצות │ מדדים │ עסקה         │
└───────────────────┬───────────────────────────┘
                     │ REST/JSON (+ session cookie)
┌───────────────────▼───────────────────────────┐
│  FastAPI backend                               │
│  ┌────────────┐ ┌───────────┐ ┌─────────────┐ │
│  │ auth        │ │ portfolio │ │ recommend.  │ │
│  │ (סיסמה+ses) │ │ (CRUD)    │ │ + indices   │ │
│  └────────────┘ └───────────┘ └─────────────┘ │
│  ┌─────────────────────────────────────────┐  │
│  │ APScheduler: job EOD יומי אחרי סגירה      │  │
│  │  → screener על S&P500+Nasdaq (~1500)     │  │
│  └─────────────────────────────────────────┘  │
│  data_fetcher (yfinance) │ indicators │ scorer │
└───────────────────┬───────────────────────────┘
                     │
              ┌──────▼──────┐
              │   SQLite     │
              └──────────────┘
```

**רכיבי backend:**

- `data_fetcher` — עוטף את `yfinance`. שתי צורות שליפה: בודדת/קבוצה קטנה
  (למסכי תיק/מדדים, "current price" בזמן טעינה) ו-batch לכל היוניברס
  (~1500 טיקרים, לריצת ה-EOD). כולל retry עם backoff; טיקר שנכשל נדלג
  ולא מפיל את כל הריצה.
- `indicators` — מחשב SMA50/SMA200, % מרחק משיא 52 שבועות, תשואה יחסית
  מול S&P500 לתקופה נתונה, מחזור מסחר ממוצע.
- `scorer` (screener) — מריץ את כללי v1 על כל היוניברס, מדרג לפי ציון
  מצרפי, מחזיר Top 10-20. הכללים/ספים מוגדרים בקובץ קונפיג נפרד (לא
  hardcoded בלוגיקה) כדי שיהיה קל להחליף אותם כשיוגדרו כללי "מיכה
  סטוקס" המדויקים.
- `auth` — סיסמה אחת (hash שמור ב-DB או env var), מנפיקה session cookie
  חתום בהתחברות. כל endpoint תחת `/api/*` (חוץ מ-`/api/auth/login`)
  דורש session תקף.
- `portfolio` — CRUD על פוזיציות וירטואליות.
- `recommendations` / `indices` — endpoints לקריאה בלבד, מחזירים את
  תוצאות ה-screener האחרון ואת רשימת המדדים שהמשתמש הגדיר.
- `scheduler` (APScheduler) — job יומי, פעם אחת אחרי סגירת המסחר
  (16:00 ET + מרווח בטיחות), מריץ screener על כל היוניברס וכותב
  ל-`screener_results`. אידמפוטנטי — upsert לפי תאריך, בטוח להריץ שוב.

**Frontend:** React (Vite) SPA, קורא ל-API של FastAPI, responsive,
מוגדר כ-PWA (manifest + service worker) כדי לאפשר "הוספה למסך הבית"
באייפון.

**Deployment:** קונטיינר Docker יחיד — FastAPI מגיש גם את קבצי ה-React
הבנויים (static build) וגם את ה-API. פריסה על שרת ענן חינמי (Railway
או Fly.io free tier).

## מודל נתונים (SQLite)

| טבלה | שדות עיקריים | הערות |
|---|---|---|
| `auth_config` | `password_hash` | שורה יחידה, משתמש אחד |
| `portfolio_positions` | `id, ticker, entry_price, stop_loss, entry_date, status (open/closed), close_date` | "מחיר נוכחי" ו-% רווח/הפסד מחושבים בזמן טעינה, לא מאוחסנים |
| `screener_results` | `run_date, ticker, score, metrics (json)` | תוצאות ריצת EOD; נשמרות כדי להציג היסטוריה/לבדוק תקינות |
| `universe_tickers` | `ticker, index_name (sp500/nasdaq)` | רשימת הטיקרים לסריקת EOD; מתעדכנת מדי פעם (מקור סטטי, למשל טבלת ויקיפדיה) |
| `watched_indices` | `symbol, display_name, sort_order` | רשימת מדדים/ETF-ים שהמשתמש בעצמו מנהל במסך המדדים |

## מסכים

1. **תיק שלי** — טבלת `portfolio_positions` פתוחות: טיקר, מחיר כניסה,
   סטופלוס, מחיר נוכחי (live), % רווח/הפסד. לחיצה על שורה → מסך עסקה
   (מכירה).
2. **המלצות** — Top 10-20 מ-`screener_results` האחרון: דירוג, טיקר,
   מחיר נוכחי, שינוי יומי %, ציון. לחיצה על שורה → מסך עסקה (קנייה).
3. **מדדים** — רשימת `watched_indices`: מחיר נוכחי, שינוי יומי %.
   מסך זה גם מאפשר הוספה/הסרה/סידור מחדש של הרשימה.
4. **עסקה** — נפתח מלחיצה על טיקר במסך אחר. קנייה: טופס מחיר קנייה +
   סטופלוס → יוצר רשומה חדשה ב-`portfolio_positions`. מכירה: מסמן
   `status=closed` לרשומה קיימת.

## מנוע המלצות — v1 (גנרי, ניתן להחלפה)

כללי מגמה/מומנטום סטנדרטיים לדירוג ובחירת Top 10-20 מתוך יוניברס
S&P500+Nasdaq (~1500 טיקרים):

1. **מגמת עלייה**: מחיר נוכחי > SMA50, וגם SMA50 > SMA200.
2. **קרבה לשיא**: מחיר בטווח 15% (קונפיגורבילי) משיא 52 השבועות.
3. **נזילות**: מחזור מסחר יומי ממוצע (dollar volume) מעל סף מינימלי,
   כדי לסנן מניות דלות-סחירות.
4. **עוצמה יחסית**: תשואת המניה ב-N השבועות האחרונים (קונפיגורבילי,
   ברירת מחדל 12 שבועות) גבוהה מתשואת S&P500 באותה תקופה.

טיקרים שעוברים את כל התנאים מדורגים לפי ציון מצרפי (שילוב של קרבה
לשיא + עוצמה יחסית), ונבחרים ה-Top 10-20. הפרמטרים (ספים, משקלים,
תקופות) יושבים בקובץ קונפיג נפרד מהלוגיקה, כדי שיהיה קל להחליף אותם
כשיוגדרו כללי "מיכה סטוקס" המדויקים.

## אבטחה

סיסמה אחת בלבד (המשתמש היחיד באפליקציה). Login endpoint בודק את
הסיסמה מול hash שמור, מנפיק session cookie חתום (HttpOnly, Secure).
כל ה-API תחת session תקף. אין ניהול משתמשים, הרשאות, או הרשמה.

## טיפול בשגיאות

- כשלון משיכת נתונים מ-`yfinance` לטיקר בודד: retry עם backoff (2-3
  ניסיונות), ואז דילוג עם לוג — לא מפיל את כל ריצת ה-screener.
- כל מסך מציג חותמת "עודכן לאחרונה ב-HH:MM" כדי שהמשתמש יידע כמה
  הנתונים המוצגים טריים.
- ריצת EOD אידמפוטנטית — upsert לפי `run_date`, בטוח להריץ שוב אם
  נכשלה באמצע.
- אם ריצת EOD נכשלת לגמרי (למשל אין אינטרנט לשרת), מסך ההמלצות ממשיך
  להציג את התוצאות האחרונות שהצליחו, עם חותמת התאריך שלהן.

## בדיקות

- טסטים יחידתיים ל-`indicators` ול-`scorer` (פונקציות טהורות, נבדקות
  עם נתוני מחיר מדומים/fixtures — לא תלויות ב-API חיצוני).
- בדיקה ידנית של 4 המסכים בדפדפן (dev server) לפני כל פריסה, כולל
  התנהגות במסך מובייל (responsive).

## מחוץ לתחום (v1)

- אין חיבור אמיתי לברוקר / ביצוע עסקאות אמיתיות.
- אין התראות push/טלגרם (הוסר מהעיצוב הקודם).
- אין תמיכה במשתמשים מרובים.
- אין נתונים בזמן אמת מלא (streaming) — מחיר "נוכחי" נשלף מ-`yfinance`
  בזמן טעינת מסך, לא בזמן אמת רציף.
